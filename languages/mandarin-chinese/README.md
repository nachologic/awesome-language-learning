# Mandarin Chinese

Resources for learning Mandarin Chinese, organized by skill.

## Courses

- [HSK Academy](https://hsk.academy/) - Vocabulary lists, grammar points and practice tests for every HSK level.
- [Yoyo Chinese](https://www.yoyochinese.com/) - Structured video courses, from pinyin and characters to intermediate conversation.
- [HelloChinese](https://www.hellochinese.cc/) - Gamified app for learning Mandarin, with handwriting and speaking practice.

## Grammar

- [Chinese Grammar Wiki](https://resources.allsetlearning.com/chinese/grammar/) - Example-rich grammar reference organized by level, from A1 to C1.

## Reading

- [Mandarin Bean](https://mandarinbean.com/) - Free graded reading passages with audio, sorted by HSK level.

## Vocabulary & Dictionaries

- [Pleco](https://www.pleco.com/) - Chinese-English dictionary app with flashcards, handwriting input and camera-based character lookup.
