# Hindi

Resources for learning Hindi, organized by skill.

## Courses

- [Duolingo Hindi](https://www.duolingo.com/course/hi/en/Learn-Hindi) - Gamified course that teaches Devanagari and everyday vocabulary.
- [I Speak Hindi](https://ispeakhindi.com/) - Podcast-style lessons covering vocabulary, grammar and culture, with transcripts.

## Listening

- [Learn Hindi with Anil Mahato](https://www.youtube.com/@AnilMahato) - Long-running YouTube channel with lessons on vocabulary, grammar and conversation.

## Vocabulary & Dictionaries

- [HinKhoj](https://www.hinkhoj.com/) - Hindi-English dictionary with example sentences, pronunciation and vocabulary tools.
- [Shabdkosh](https://www.shabdkosh.com/) - Hindi-English dictionary with definitions, pronunciation and examples.
