# Turkish

Resources for learning Turkish, organized by skill.

## Courses

- [Polly Lingual Turkish](https://pollylingu.al/tr/en) - Interactive Turkish lessons with native audio, from beginner to advanced.
- [Turkishaholic](https://turkishaholic.com/) - Grammar lessons, vocabulary lists and speaking practice, with a free level test.

## Grammar

- [Manisa Turkish](https://www.turkishlanguage.co.uk/) - In-depth free reference for Turkish grammar, with clear explanations and examples.

## Vocabulary & Dictionaries

- [TDK Sozluk](https://sozluk.gov.tr/) - The official dictionary of Turkish, from the Turkish Language Association.
